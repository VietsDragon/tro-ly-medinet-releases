# Trợ lý Medinet – Releases

Kho phát hành chính thức của ứng dụng **Trợ lý Medinet**.

- Bản portable dành cho Windows 10/11 được phát hành tại mục **Releases**.
- Ứng dụng đọc `latest.json` để kiểm tra phiên bản mới.
- Mỗi gói cập nhật được đối chiếu SHA-256 trước khi cài.
- Kho này không chứa tài khoản, mật khẩu, cookie Medinet hoặc dữ liệu người bệnh.
- Mã nguồn ứng dụng không được lưu trong repository phát hành công khai này.

> Chỉ tải bản cập nhật từ trang Releases của repository này.
